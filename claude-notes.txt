## HOW TO ADD A NEW LESSON (the entire workflow)

1. Create `/lessons/{w}-{d}-{lang}.js`
2. In that file, add to the global `LESSONS` object:
   `LESSONS['{w}-{d}-{Lang}'] = { ... lesson data ... };`
3. In `dashboard.js` find the week in CURRICULUM array and set `hasLesson: true` for that day
4. In `index.html` add ONE line before `</body>`:
   `<script src="lessons/{w}-{d}-{lang}.js"></script>`

That is it. The engine renders everything automatically.

## THE LESSON DATA STRUCTURE

Every lesson file exports one object into LESSONS. Here is the complete schema:

```javascript
LESSONS['week-day-Lang'] = {
  color:    'gold',          // 'gold' for Hebrew/Latin, 'blue' for Greek

  subtitle: 'Week X · Day Y · Language Name',
  title:    'The lesson title',
  intro:    'Opening paragraph shown in the intro panel.',

  sections: ['Introduction','Panel 2 Name','Panel 3 Name','Panel 4 Name','Panel 5 Name','Quiz','Complete'],
  // Always 7 sections. The engine builds navigation from this array.

  beforeYouBegin: `HTML string — content for the intro panel`,

  // Panel 2 — alphabet/overview panel
  alphabetIntro: 'Intro paragraph for panel 2',
  alphabetNotes: `HTML string — additional notes`,
  alphabet: [
    { ch:'א', name:'Aleph', sound:'Silent', n:1, t:true },
    // t:true = highlight this item in today's accent colour
  ],

  // Panel 3 — focus letters / key concepts
  focusLetters: [
    { ch:'א', name:'Aleph', trans:'(silent)', desc:'Description', ex:'Example' },
  ],
  deepDive: `HTML string — main explanatory content`,

  // Panel 4 — writing practice
  writing: [
    { ch:'א', name:'Name', steps:['Step 1','Step 2','...'] },
  ],

  // Panel 5 — vocabulary + scripture
  vocab: [
    { ch:'word', trans:'transliteration', meaning:'English', note:'Grammar note' },
  ],
  scriptureRef: 'Genesis 1:1',
  scripture: { orig:'Original text', trans:'Transliteration', eng:'"English." — Ref' },
  scriptureNote: 'What to find in the text',
  scriptureTip:  '<strong>💡 Tip:</strong> HTML tip box content',

  // Panel 6 — quiz (always exactly 5 questions)
  quiz: [
    {
      q:    'Question text',
      ch:   'Character to display large (or empty string)',
      opts: ['A','B','C','D'],
      ans:  1,    // 0-indexed
      ok:   'Correct feedback',
      no:   'Wrong feedback',
    },
  ],

  // Panel 7 — completion
  completionNote: 'Summary of lesson',
  nextDay:        'Day X: Next Title →',
};
```

## LESSONS BUILT (25 total, Weeks 1–5)

### Week 1 — Alphabet Foundations
- 1-1-Hebrew: Hebrew alphabet letters 1–5 (Aleph–He)
- 1-2-Greek:  Greek alphabet letters 1–5 (Alpha–Epsilon)
- 1-3-Hebrew: Hebrew letters 6–10 (Vav–Yod); divine name יהוה
- 1-4-Greek:  Greek letters 6–10 (Zeta–Kappa); Theos, Iesous, Kyrios
- 1-5-Hebrew: Hebrew letters 11–15 (Kaf–Samekh); Melech, Kavod, Nefesh, Mashiach

### Week 2 — Completing the Alphabet
- 2-1-Hebrew: Hebrew letters 16–22 + final forms; Shalom, Torah, Kadosh, Ruach
- 2-2-Greek:  Greek letters 11–17 (Lambda–Rho); Pistis, Mathetes, Hodos, Aletheia
- 2-3-Hebrew: Complete Niqqud vowel system
- 2-4-Greek:  Greek letters 18–24 (Sigma–Omega); Christos, Soteria, Telos, Psyche
- 2-5-Hebrew: Reading first Hebrew sentences; Psalm 23:1–3; four key prefixes

### Week 3 — Latin Begins + Reading
- 3-1-Latin:  Latin alphabet; ecclesiastical pronunciation
- 3-2-Greek:  Greek grammar I — cases, article, first declension
- 3-3-Hebrew: Hebrew grammar I — Qal Perfect verb
- 3-4-Latin:  Latin grammar I — six cases, 1st and 2nd declension
- 3-5-Hebrew: John 1:1 in all three languages (key: '3-5-Hebrew')

### Week 4 — Grammar Foundations
- 4-1-Hebrew: Qal Imperfect; YTAN prefixes; Vav-consecutive
- 4-2-Greek:  Present Active Indicative; εἰμί paradigm; seven I AM sayings
- 4-3-Latin:  1st conjugation present; esse paradigm; Creed
- 4-4-Hebrew: Construct chains — Word of LORD, Son of Man, Spirit of God
- 4-5-Hebrew: Week 1–4 review all three languages

### Week 5 — Reading Scripture
- 5-1-Hebrew: Psalm 23 full reading (all 6 verses); hesed
- 5-2-Greek:  John 1:1–5; ἦν vs ἐγένετο; light shines in darkness
- 5-3-Latin:  Pater Noster full; subjunctive mood; fiat voluntas tua
- 5-4-Hebrew: Genesis 1:1–5 full; bara; tohu vavohu; ruach Elohim
- 5-5-Greek:  Romans 3:21–26; δικαιοσύνη; δωρεάν; ἱλαστήριον; passive voice as grace

## PEDAGOGICAL RULES

1. Every lesson: exactly 7 sections, ~90 minutes
2. 5 letters OR 1 grammar concept with 5 focus items per lesson
3. Every vocabulary word tied to a specific scripture passage
4. Every quiz answer (right and wrong) includes full explanatory feedback
5. Hebrew: Masoretic Text (BHS) | Greek: UBS5/NA28 | Latin: Jerome's Vulgate
6. Language colours: Hebrew=brown/gold, Greek=forest green, Latin=terra cotta
